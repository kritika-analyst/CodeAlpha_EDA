# Netflix Dataset Exploratory Data Analysis (EDA)

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset downloaded from Kaggle.

The main goal of this project is to understand the dataset structure, analyze missing values, and visualize trends using Python libraries.

---

## Dataset Used
Dataset: Netflix Movies and TV Shows Dataset

Source: Kaggle

File Used:
- netflix_titles.csv

---

## Libraries Used
- Pandas
- Seaborn
- Matplotlib

---

## Tasks Performed

### Data Exploration
- Loaded dataset using pandas
- Displayed first 5 rows
- Checked dataset shape
- Viewed column names
- Analyzed data types

### Missing Value Analysis
- Checked null values in each column

### Data Visualization
Created visualizations for:
- Movies vs TV Shows count
- Netflix content release trend
- Top 10 countries producing Netflix content

---

## Key Insights
- Netflix contains more Movies than TV Shows
- Content production increased rapidly after 2015
- Some columns contain missing values, especially director and country
- United States produces the highest Netflix content
